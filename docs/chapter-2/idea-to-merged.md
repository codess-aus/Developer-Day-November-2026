# From Idea to Merged with Copilot App

![Title slide: From Idea to Merged with Copilot App.](../assets/9-from-idea-to-merged-with-copilot-app.png){ .slide loading=lazy }

This session follows a change from first idea to merged pull request using the GitHub Copilot app.

The app is a desktop application for agent-driven development. It brings parallel workstreams, GitHub integration and pull request lifecycle management into one place. It is built on GitHub Copilot CLI, so CLI features such as `/chronicle` work on your app sessions too.

Source: [GitHub Copilot app](https://docs.github.com/copilot/concepts/copilot-surfaces/github-copilot-app)
