# Start another task while agents keep working

![Slide: Start another task while agents keep working. The Copilot app sessions list showing several tasks running side by side.](../assets/13-multitasking.png){ .slide loading=lazy }

Each task runs in its own session, so several tasks can overlap without requiring your constant attention.

## Tips

- Run sessions in separate worktrees to progress on several tasks in parallel, or work in an existing checkout.
- Use a cloud sandbox to keep a session off your machine or run several heavy tasks at once.
- Use **Manage sessions** in the app settings to search, archive, delete and restore sessions and chats.
- Sessions continue across clients. In VS Code, the new Agent Host keeps work running after you close the window, and you can pick a session up in the app, GitHub Mobile, github.com or Copilot CLI.
