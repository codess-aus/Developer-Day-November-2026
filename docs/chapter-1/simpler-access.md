# Simpler access to AI across your development organisation

![Slide: GitHub Enterprise. Includes access to Copilot. A billing and licensing screen shows Copilot alongside Enterprise Cloud and Advanced Security.](../assets/3-simpler-access-to-ai-across-your-development-organization.png){ .slide loading=lazy }

**GitHub Enterprise** now includes access to Copilot for customers who choose this offering. That helps reduce barriers to AI adoption across the organisation.

**Takeaway:** bring AI into the workflows your team already uses, across Plan, Build, Review and Ship.

## How the new model works

- Enterprises working with a GitHub or Microsoft account team can get Copilot included with GitHub Enterprise for every licensed user.
- Users without a GitHub Enterprise license get the same access through Copilot Standalone at $10 per user per month.
- There is no included usage allowance. AI usage is metered from the first request against your enterprise budget.
- Enterprise owners still assign Copilot seats to members, teams or organisations.
- Copilot Business and Copilot Enterprise remain available. You cannot mix them with Copilot access in the same enterprise.
