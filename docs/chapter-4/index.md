## Latest from GitHub and Microsoft Learn

The GitHub Copilot modernization agent runs from the Modernize CLI and gives agentic, end-to-end modernization.

- Assess multiple applications and repositories at once, map dependencies and generate cloud readiness scores.
- Run framework upgrades, language version migrations, containerisation and cloud service integrations as repeatable workflows.
- Review, refine and approve an editable plan before execution.
- Encode your standards once as reusable skills, then apply them across many applications.

Source: [GitHub Copilot Modernization Agent Overview](https://learn.microsoft.com/en-us/azure/developer/github-copilot-app-modernization/modernization-agent/overview)
